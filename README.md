## What it covers

- Hashtag volume
- Trending hashtags
- Trending searches

| Data | Ask with | What it measures |
|---|---|---|
| History and growth | a keyword: hashtag or topic | TikTok hashtag volume |
| Live board: TikTok Trending Hashtags | no keyword | Top trending hashtags on TikTok |
| Live board: TikTok Trending Hashtags by Category | no keyword | TikTok trending hashtags split by industry board |
| Live board: TikTok Trending Searches | no keyword | Top trending search terms on TikTok |

## How to ask

Pass a hashtag or topic for volume. Trending hashtags and trending searches need no keyword. The hashtag category board needs a category name, not a keyword.

**Good to know:** This is hashtag and search interest, plus those live boards. It does not return video view counts or follower counts.

## FAQ

**Do I need a hashtag for the trending list?**  
No. Trending hashtags and trending searches need no keyword. Pass a hashtag or topic only when you want volume over time.

**Are category boards included?**  
Yes. TikTok hashtag boards can be split by category.

**Is the TikTok connector free?**  
Yes. The free plan has 100 requests a month and includes every source. No credit card. Paid plans start at $19 a month for 1,000 requests.

**Which AI apps work with it?**  
Claude, ChatGPT, Cursor, VS Code, Claude Code, Grok, Muse, Perplexity, Gemini, Copilot, Windsurf and any app that supports MCP connectors.
